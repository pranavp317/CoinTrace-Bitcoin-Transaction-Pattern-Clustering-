# CoinTrace-Bitcoin-Transaction-Pattern-Clustering-
Bitcoin transaction pattern analysis and clustering using machine learning to identify related transaction behaviours in the Elliptic dataset.
# Dataset

This project uses the Elliptic Bitcoin Transaction Dataset.

The dataset contains:
- elliptic_txs_features.csv
- elliptic_txs_classes.csv
- elliptic_txs_edgelist.csv

The raw dataset is not included in this repository because of its large size.

Download the dataset and place the files inside this `data/` directory.
